## About

I am a software engineer focused on turning ambitious ideas into **production-grade products**. My work sits at the intersection of **AI / Machine Learning**, **Full-Stack Engineering**, and **thoughtful product design** — from autonomous learning platforms to real-time computer-vision interfaces.

- 🧠 **AI / ML** — Generative AI (LLM agents, RAG, summarization) and Computer Vision (Vision Transformers, MediaPipe, deepfake detection).
- 🏗️ **Full-Stack** — React 19, Next.js, TypeScript, Python & Django on top of Supabase / PostgreSQL.
- 🎯 **Product mindset** — I care about performance, accessibility, security (RLS, auth) and shipping polished experiences, not prototypes.
- ⚙️ **Systems thinking** — layered, self-healing architectures and automation pipelines that run end to end.

**Open To** — Open-source collaboration · AI / ML & Full-Stack opportunities · Freelance product engineering.
