## Sobre

Sou estudante de **Ciência da Computação no IDP** e engenheiro de software focado em transformar ideias ambiciosas em **produtos reais e de produção**. Meu trabalho vive na interseção entre **IA / Machine Learning**, **Engenharia Full-Stack** e **design de produto** — de plataformas autônomas de aprendizado a motores forenses de áudio e interfaces de visão computacional em tempo real.

- 🧠 **IA / ML** — IA Generativa (agentes com LLM, RAG, sumarização) e Visão Computacional / Forense de Áudio (Wav2Vec2, Spectrogram Transformers, MediaPipe).
- 🏗️ **Full-Stack** — React 19, Next.js, TypeScript, Python e Django sobre Supabase / PostgreSQL.
- 🎯 **Mentalidade de produto** — priorizo performance, acessibilidade, segurança (RLS, auth) e experiências polidas, não protótipos.
- ⚙️ **Pensamento sistêmico** — arquiteturas em camadas, auto-recuperáveis, e pipelines de automação ponta a ponta.

**Aberto a** — Colaboração open source · Oportunidades em IA / ML e Full-Stack · Engenharia de produto freelance.

## Projetos em Destaque

<details open>
<summary><b>🌌 IDP Core — Inteligência Acadêmica Autônoma (SaaS)</b></summary>

<br/>

Plataforma autônoma que transforma o caos dos materiais acadêmicos em um fluxo de inteligência destilada, movida pela **Arquitetura Onyx** e IA generativa. Interface premium com glassmorphism, resumos no estilo NotebookLM e quizzes de fixação gerados automaticamente.

| Aspecto | Detalhe |
| :------ | :------ |
| **Stack** | React 19 · Python (Agentic) · Supabase · Google Gemini |
| **Escala** | SaaS multi-módulo — auth, dashboard, ingestão de materiais e motor de guias de estudo |
| **Performance** | Ingestão via HTTP direto + cache de resumos para recuperação rápida |
| **Segurança** | Supabase Auth + Row-Level Security (RLS) |
| **Impacto** | Converte material de aula (PDF / imagem / texto) em guias de estudo magistrais |
| **Repositório** | [github.com/TEDDyx86/IDPCoreSAAS](https://github.com/TEDDyx86/IDPCoreSAAS) |

</details>

<details>
<summary><b>🛡️ ConfereAI — Motor Forense de Áudio Neural</b></summary>

<br/>

Plataforma de cibersegurança de alta performance para identificar **clonagem de voz e fraudes de áudio** com precisão forense. Usando o **Protocolo de Rigor V3**, combina múltiplos motores neurais para detectar micro-imperfeições acústicas imperceptíveis ao ouvido humano.

| Aspecto | Detalhe |
| :------ | :------ |
| **Stack** | Python 3.10 · FastAPI · Wav2Vec2 · AST (Spectrogram Transformer) · Docker · Hugging Face |
| **Escala** | Dual-Engine (HyperMoon + AST) com decisão Bayesiana e fine-tuning via Google Colab (T4) |
| **Performance** | Turbo Inference com Quantização Dinâmica (FP16) para análise rápida em CPU |
| **Segurança** | Detecção forense de áudio sintético (RVC, ElevenLabs) com XAI (mapa de calor temporal) |
| **Impacto** | Identifica fraudes de voz com evidência visual de onde a anomalia foi detectada |
| **Repositório** | [github.com/TEDDyx86/confereAI](https://github.com/TEDDyx86/confereAI) · [Demo](https://huggingface.co/spaces/TEDDyx86/confereai-dev) |

</details>

<details>
<summary><b>👁️ VisionFlow — UX Touchless com Visão Computacional</b></summary>

<br/>

Motor de interface web **sem toque**, feito para acessibilidade e higiene. Usando visão computacional no navegador, o usuário controla totens de autoatendimento com gestos das mãos (pinça para clicar, arraste para navegar). Modular e white-label por design.

| Aspecto | Detalhe |
| :------ | :------ |
| **Stack** | JavaScript · MediaPipe Hands · Visão Computacional · Gemini |
| **Escala** | Motor white-label para totens, adaptável a múltiplos ambientes |
| **Performance** | Detecção de landmarks e mapeamento de gestos em tempo real no navegador |
| **Segurança** | Privacy-first — o processamento fica no cliente, sem envio de imagem |
| **Impacto** | Interação higiênica e acessível para ambientes públicos e corporativos |
| **Repositório** | [github.com/TEDDyx86/VisionFlowV2](https://github.com/TEDDyx86/VisionFlowV2) |

</details>
